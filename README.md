# 📦 ATK Inventory Management System

Enterprise Office Stationery & Inventory Management Platform

Built with Go 1.26 + Gin + GORM + MySQL, Angular 22 + Signals + Tailwind v4.

## ✨ Features
- Role-Based Access Control (RBAC)
- Multi-level Approval Workflow
- QR Code Integration
- Excel Import/Export
- Real-time Dashboard & Analytics

## 🛠 Tech Stack
- **Backend:** Go 1.26, Gin, GORM, MySQL 8.4
- **Frontend:** Angular 22, Signals, Tailwind CSS v4.3.3
- **Auth:** JWT + bcrypt
